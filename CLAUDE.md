# demontazhnye_raboty — сайт «Под Ноль»

## Что это
Статический лендинг (чистые HTML/CSS/JS, без сборки) демонтажной компании
«Под Ноль»: демонтаж и подготовка квартир/офисов к ремонту, Москва.
Язык — русский. Сделан на кодовой базе voidaform.ru (репо `adriaaante/voidaform.ru`)
с другой палитрой и контентом — стили, JS и обработчик заявок общего происхождения,
но живут независимо: правки одного сайта в другой не переносятся автоматически.

- **Телефон +7 (987) 778-88-94** — актуальный номер заказчика (09.2026),
  стоит на сайте (tel:, wa.me, t.me, JSON-LD) и в фиде Авито. На момент
  замены номер ещё не был подключён — поэтому показы объявлений на паузе.
  Реквизиты юрлица заказчик пришлёт отдельно — тогда добавить
  `.footer__legal` с юрлицом.
- Юрлицо в privacy/consent — ООО «ГПУ 3» (то же, что на voidaform.ru);
  подтверждения от заказчика пока нет, может смениться.

## Структура
- `index.html` — единственная содержательная страница: hero (сплит с фото),
  ценность (#value), услуги (#services), фотоблок 2×2, процесс (#process, тёмный),
  FAQ, контакты + форма. JSON-LD: ProfessionalService + OfferCatalog, FAQPage.
- `privacy.html`, `consent.html`, `404.html` — генерировались скриптом из шапки/подвала
  index (разово); дальше править руками, они маленькие.
- `css/style.css` — копия стилей voidaform с правками: акцент `#E8641B` (оранжевый),
  `--dark #17181A`, заголовки weight 600 (был 300), `.photos` (сетка фото),
  `.footer__wordmark`. Шрифт — тот же локальный Montserrat (`assets/fonts/`).
- `js/main.js` — копия voidaform (меню, модалка, fab, формы); телефон и подпись
  заявки заменены. Формы шлют POST на `data-endpoint` (`api/lead.php`),
  при недоступности (на GitHub Pages PHP нет) открывают WhatsApp — это штатный путь.
- **Заявки идут через общий обработчик voidaform**: у форм
  `data-endpoint="https://voidaform.ru/api/lead.php"` + скрытое поле
  `site=подноль.рф` — заявка падает в тот же Telegram-чат с пометкой сайта.
  CORS-допуск домена прописан в `api/lead.php` репозитория voidaform.ru
  (allowlist: подноль.рф в punycode + adriaaante.github.io). Секреты
  TG_BOT_TOKEN/TG_CHAT_ID этому репо НЕ нужны. Локальный `api/lead.php` —
  резерв на случай, если сайты решат разъехаться по ботам; держать копией
  файла из voidaform.ru.
- **Защита от ботов** живёт в обработчике voidaform (описана в его CLAUDE.md).
  Со стороны этого сайта: `js/main.js` при первом касании формы берёт
  подписанный токен `GET …/lead.php?token=1` и шлёт его с заявкой; на ошибку
  токена берёт новый и повторяет один раз, потом WhatsApp. Если обработчик
  токен не выдал (старая версия, сеть), заявка уходит без него — старый
  сервер её примет, новый отправит клиента в WhatsApp. Без JS не отправить.
- `assets/img/*.jpg` — изображения сгенерированы (Higgsfield nano_banana_pro),
  реальных фото объектов пока нет: hero (896×1200), screed/waste/office/shell (1376×768).
- Логотип — инлайн SVG (оранжевый квадрат + перечёркнутый ноль «Ø»), файл только
  `favicon.svg`. Название «Под Ноль» = отраслевой термин «демонтаж под ноль».

  `https://xn--d1aofccc0h.xn--p1ai/avito/avito.xml`, режим auto, раз в час.

- Фид и тексты собирает `scripts/build_feed.py` из каталога `scripts/ads.py`
  (19 объявлений, у трёх ещё нет цены — они в фид не идут). На выходе
  `avito/avito.xml` и `avito/OBYAVLENIYA.md`. Картинки — `avito/img/`
  (`-1` обложка на фото, `-2` карточка условий), закрыты в robots.txt.
- **Пауза показов** — флаг `PAUSED` в `scripts/build_feed.py`. На паузе в фиде
  остаётся одна заглушка с датой начала через год, рабочих объявлений нет, и
  автозагрузка снимает всё с публикации («Удалено из файла»); так объявления
  снимали 16.09.2026 выгрузкой 599697847. Возврат — `PAUSED = False`,
  пересобрать фид, запушить, дождаться выгрузки. Проверено 20.09.2026: Авито
  поднимает те же самые объявления с прежними id, а не создаёт новые, —
  история и статистика сохраняются.
- Грабли автозагрузки, проверено 16.09.2026:
  - даты в фиде Авито читает **по Москве**, сборка в контейнере идёт в UTC —
    поэтому в скрипте явный `MSK`;
  - `DateEnd` **снять объявление не может вообще**: в прошлом — выгрузка
    отвечает «Прошла дата окончания размещения» и пропускает объявление,
    в будущем — «Без изменений», срок размещения у живого объявления не
    меняется. Единственный рычаг из фида — убрать объявление из файла;
  - снять объявление через API нельзя: в `/core/v1` нет ни stop, ни delete,
    только чтение (`GET /core/v1/accounts/{user}/items/{id}/`); мгновенно
    снимается только руками в кабинете;
  - **пустой фид не годится** — валидатор считает его несоответствующим
    формату, выгрузка падает с ошибкой и ничего не меняет; поэтому на паузе
    в файле живёт заглушка `pauza-zaglushka` с датой начала через месяц;
  - запуск выгрузки — `POST /autoload/v1/upload`, **не чаще раза в час**;
  - несколько значений одного параметра — вложенные `<Option>`, не «|»;
  - **картинку по тому же адресу Авито не перечитывает**: подменили файл на
    хостинге — выгрузка отчитается «Без изменений», в объявлении останется
    старое фото. Поэтому в `ads.py` есть `img_rev`: с ним фид ссылается на
    `{id}-{n}-r{N}.jpg`, файлы переименовываются вместе с ним.
- **Справочник полей категории — внутренний API документации Авито.** Это
  самый короткий путь, не надо угадывать значения:
  `GET https://www.avito.ru/web/1/autoload/user-docs/tree` — дерево категорий
  с node_id (77203 «Снос и демонтаж», 77204 «Фасадные работы»), затем
  `GET .../user-docs/category/{node_id}/fields` — все поля с флагом
  обязательности, списком допустимых значений, примерами XML и зависимостями
  между полями. Отвечает только с браузерными заголовками (User-Agent, Referer
  на страницу документации, Accept: application/json) и часто отдаёт 429 —
  помогает цикл из 10–15 попыток с паузой.
- Значения параметров можно также сверять **публичным валидатором Авито**
  (медленнее: подбор вслепую, зато проверяет файл целиком):
  `POST https://autoload.avito.ru/api/v2/public/xml_checker/upload/` — сырым
  телом запроса, `Content-Type: text/plain`; результат — GET
  `.../xml_checker/result/{id}/` (HTML). Обёртка — `scratchpad/avito/probe.sh`.
  Способ подбора: кладём в один файл несколько копий объявления с разными
  значениями и разными `<Id>`, смотрим, какие прошли.
