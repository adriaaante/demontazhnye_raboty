# demontazhnye_raboty — сайт «Под Ноль»

## Что это
Статический лендинг (чистые HTML/CSS/JS, без сборки) демонтажной компании
«Под Ноль»: демонтаж и подготовка квартир/офисов к ремонту, Москва.
Язык — русский. Сделан на кодовой базе voidaform.ru (репо `adriaaante/voidaform.ru`)
с другой палитрой и контентом — стили, JS и обработчик заявок общего происхождения,
но живут независимо: правки одного сайта в другой не переносятся автоматически.

- **Телефон +7 (909) 341-07-85 — ВРЕМЕННЫЙ** (из реквизитов ООО «ГПУ 3»);
  заказчик пришлёт постоянный номер и реквизиты — тогда заменить по всему
  сайту (tel:, wa.me, t.me, JSON-LD) и добавить `.footer__legal` с юрлицом.
- Юрлицо в privacy/consent — ООО «ГПУ 3» (то же, что на voidaform.ru);
  подтверждения от заказчика пока нет, может смениться.

## Структура
- `index.html` — единственная содержательная страница: hero (сплит с фото),
  ценность (#value), услуги (#services), фотоблок 2×2, процесс (#process, тёмный),
  FAQ, контакты + форма. JSON-LD: ProfessionalService + OfferCatalog, FAQPage.
- `privacy.html`, `consent.html`, `404.html` — генерировались скриптом из шапки/подвала
  index (разово); дальше править руками, они маленькие.
- `css/style.css` — копия стилей voidaform с правками: акцент `#E8641B` (оранжевый),
  `--dark #17181A`, заголовки weight 600 (был 300), `.photos` (сетка фото),
  `.footer__wordmark`. Шрифт — тот же локальный Montserrat (`assets/fonts/`).
- `js/main.js` — копия voidaform (меню, модалка, fab, формы); телефон и подпись
  заявки заменены. Формы шлют POST на `data-endpoint` (`api/lead.php`),
  при недоступности (на GitHub Pages PHP нет) открывают WhatsApp — это штатный путь.
- `api/lead.php` — обработчик заявок в Telegram; НЕ работает на Pages, задел
  на будущий PHP-хостинг. Конфиг `api/config.php` в репо не хранится.
- `assets/img/*.jpg` — изображения сгенерированы (Higgsfield nano_banana_pro),
  реальных фото объектов пока нет: hero (896×1200), screed/waste/office/shell (1376×768).
- Логотип — инлайн SVG (оранжевый квадрат + перечёркнутый ноль «Ø»), файл только
  `favicon.svg`. Название «Под Ноль» = отраслевой термин «демонтаж под ноль».

## Деплой
- GitHub Pages через Actions (`.github/workflows/pages.yml`): push в `main` →
  артефакт (всё, кроме `scripts/`, `CLAUDE.md`, `.git*`) → deploy-pages.
  `configure-pages` с `enablement: true` включает Pages сам при первом прогоне.
- URL: https://adriaaante.github.io/demontazhnye_raboty/
- **Пути относительные** (сайт в подпапке Pages). Canonical/OG/sitemap/robots
  указывают на Pages-URL — при переезде на домен заменить во всех четырёх местах.
- Цены на сайте не указываются — «смета по фото за 1 час», фиксация в договоре.

## Команды
- Локально: `python3 -m http.server 8766` из корня (порт 8766, чтобы не
  конфликтовать с voidaform на 8765 в той же сессии).
- Адаптивный аудит: `NODE_PATH=/opt/node22/lib/node_modules node scripts/audit_responsive.js`
  (4 страницы × 23 разрешения; ждать «✓ проблем не найдено»).
